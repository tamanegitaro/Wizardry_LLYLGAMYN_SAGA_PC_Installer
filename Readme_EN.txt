Wizardry: Llylgamyn Saga Installer v2.0.1
by tamanegi_taro 2026/11/25

[How to Use]
1. Insert an original PC CD of Wizardry: Llylgamyn Saga(DigiCube version) into your computer.
2. Run LlylgamynSagaSetup_EN.exe (English) or LlylgamynSagaSetup_JP.exe (Japanese).
3. Choose an installation folder and select any desired options.
   [ ] DirectX compatibility fix (dgVoodoo2)
   [ ] BGM playback fix
   [ ] Force software-emulated 3D display mode
   [ ] Create shortcuts

[Distribution Folder Layout]
LlylgamynSagaSetup_JP.exe
LlylgamynSagaSetup_EN.exe
Readme_JP.txt
Readme_EN.txt
runtime/
    dgVoodoo2_87_6.zip   (original ZIP; do not modify or recompress)

Game data is copied from the original CD. You may overwrite files in an existing
installation folder; files with matching names, including saves or settings,
may be overwritten. Back up your data before installing.

[Uninstall]
Uninstall the game from Windows Settings > Installed apps.
The installer tracks the files it installs. Save files and modified files
are protected from automatic removal.
